# Espacio privado del GM

Fecha: 2026-11-05.

A petición del creador se diseña el espacio de trabajo del GM en
`Transcendence-narrative-engine/docs/gm-private-workspace-design.md`, enlazado desde
el contrato del GM y el README del motor. Los detalles operativos quedan para revisión.

Se revisan la proyección actual de `GMPort`, los registros de preparación y el estado
de intervenciones, junto con el acceso canónico de Publications y el contrato del
módulo. Se reutilizan como base sin crear otro almacenamiento ni modificar formatos.

La propuesta separa fuentes, mundo confirmado, participantes, preparación e intenciones,
procesos en marcha, experiencia presentada y pendientes. Distingue una idea todavía
revisable de una existencia oculta ya confirmada. Define una vista de trabajo acotada,
consultas con procedencia y operaciones propuestas de IA, sin acceso a cuadernos
privados de protagonistas o a señales técnicas de sus escrituras.

La revisión de intenciones, selección de contexto del GM, recuperación específica de
continuidad y adaptador del resolvedor siguen pendientes de implementación. Se incluyen
criterios de comprobación para esos incrementos. No se ejecutan modelos, escenas,
dados o cambios de protagonistas; no se modifican fuentes de campaña o Publications.

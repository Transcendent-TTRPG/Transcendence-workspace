# Work Cards

This folder stores reusable templates for workflow execution.

Work cards exist so that workflows can be run as explicit processes instead of
being treated as informal advice.

Each work card should capture:
- owning workflow
- linked workflows
- scope
- sources
- phase checkpoints
- blockers
- acceptance closure
- change impact

## Templates currently available

- [Technique Work Card Template](./technique-workcard-template.md)
- [Simulation Port Work Card Template](./simulation-port-workcard-template.md)
- [Species Audit Work Card Template](./species-audit-workcard-template.md)

## Usage rule

When an agent starts a substantial workflow-governed task, it should copy or
fill the nearest matching template rather than inventing a structure ad hoc.

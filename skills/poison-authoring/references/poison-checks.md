# Poison Authoring Checks

Every poison run should leave explicit toxic life-cycle clarity.

## Boundary checks

- poison scope explicit
- delivery or exposure model explicit

## Grammar checks

- taxonomy explicit
- dose logic explicit
- onset timing explicit
- severity logic explicit
- persistence / decay logic explicit
- antidote / cleansing logic explicit
- neutralization conditions explicit

## Inheritance checks

- family-level doctrine explicit
- per-entry overrides explicit
- exceptions explicit

## Downstream checks

- simulator implications explicit
- publication implications explicit
- upstream blockers explicit

## Closure checks

- poison-family status explicit
- pending exceptions explicit
- change impact explicit

# Technique Play Surface Checks

Every play-surface run should leave explicit alignment.

## Authority checks

- authority source confirmed
- authority stable enough for final surface
- authority-only fields not copied blindly into publication artifacts

## Surface checks

- canonical field set present
- category compression consistent
- requirements reduced to real game mechanisms
- active-technique requirements do not contain ordinary tactical context unless that context is a formal game gate
- keywords add information instead of repeating visible fields
- effect wording is tactical and exact
- exact quantities stay exact; compression does not introduce approximation language

## Alignment checks

- core and card say the same Technique
- abbreviations do not change meaning
- card-specific compression remains semantically safe

## Output checks

- core entry updated
- card source updated
- print sheet state updated or explicitly left partial

## Closure checks

- alignment reviewed
- pending items explicit
- change impact explicit

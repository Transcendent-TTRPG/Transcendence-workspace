# Technique Play Surface Checks

Every play-surface run should leave explicit alignment.

## Authority checks

- authority source confirmed
- authority stable enough for final surface
- authority-only fields not copied blindly into publication artifacts

## Surface checks

- canonical field set present
- flavor text feels species-true, compact, and memorable rather than inflated
- flavor text is short and concrete enough to scan fast
- category compression consistent
- requirements reduced to real game mechanisms
- active-technique requirements do not contain ordinary tactical context unless that context is a formal game gate
- named kit families survive into final surface when they are real game gates
- keywords add information instead of repeating visible fields
- player-facing labels are localized to the publication language
- roll and payload notation matches the publication language standard
- ordinary player-facing words are written in full instead of being shortened for layout
- any remaining abbreviation is canonical rules notation rather than ad hoc compression
- effect wording is tactical and exact
- exact quantities stay exact; compression does not introduce approximation language
- cleanup path is explicit when the technique creates a state that existing rules can clear

## Roll and payload checks

- weapon-rooted techniques use `T.A.` for the primary roll and `T.I.` when damage resolves
- non-weapon specialization techniques use `T.E.` for the primary roll; Impact is `—` unless direct damage also applies
- techniques with no roll show `—` in the primary roll field
- saving roll is shown only when there is a distinct negating roll before the effect takes hold
- for weapon-rooted techniques, saving roll is `R.R.` (ailment/alteration) or `T.D.` when a defense gate applies separately
- for non-weapon specialization techniques, saving roll is the opposing specialization that most directly suppresses the primary channel, expressed as `T.E. (Competencia)`
- saving roll cell is `—` or omitted when there is no distinct negating roll — vague contextual opposition does not qualify

## Alignment checks

- core and card say the same Technique
- abbreviations do not change meaning
- card-specific compression remains semantically safe

## Output checks

- core entry updated
- card source updated
- print sheet state updated or explicitly left partial

## Closure checks

- alignment reviewed
- pending items explicit
- change impact explicit

# Status Family Checks

Every family run should leave explicit structure, not only content.

## Boundary checks

- family scope explicit
- family exclusions explicit when needed

## Grammar checks

- taxonomy explicit
- application model explicit
- resolution model explicit
- duration / expiry model explicit
- recovery / treatment / release logic explicit

## Inheritance checks

- family-level doctrine explicit
- per-entry inheritance explicit
- exceptions explicit

## Downstream checks

- simulator implications explicit
- publication implications explicit
- upstream blocker status explicit

## Closure checks

- family status explicit
- pending exceptions explicit
- change impact explicit

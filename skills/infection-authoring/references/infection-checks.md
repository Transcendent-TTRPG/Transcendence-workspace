# Infection Authoring Checks

Every infection run should leave explicit life-cycle clarity.

## Boundary checks

- infection scope explicit
- vector or exposure model explicit

## Grammar checks

- taxonomy explicit
- severity logic explicit
- progression logic explicit
- persistence / expiry logic explicit
- treatment / cleansing logic explicit
- release conditions explicit

## Inheritance checks

- family-level doctrine explicit
- per-entry overrides explicit
- exceptions explicit

## Downstream checks

- simulator implications explicit
- publication implications explicit
- upstream blockers explicit

## Closure checks

- infection-family status explicit
- pending exceptions explicit
- change impact explicit

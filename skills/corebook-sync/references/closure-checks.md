# Corebook Sync Closure Checks

Every sync run should leave explicit publication status.

## Mapping checks

- source authority identified
- affected publication sections identified
- language impact identified

## Sync checks

- ES status explicit
- EN status explicit
- terminology alignment explicit
- explanatory or example text impact explicit

## Authority checks

- publication does not redefine authority
- authority/publication disagreement is either resolved or recorded

## Closure checks

- sync needed vs not needed explicit
- pending drift explicit
- change impact explicit

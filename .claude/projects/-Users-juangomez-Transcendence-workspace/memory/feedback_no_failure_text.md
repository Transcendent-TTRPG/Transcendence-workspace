---
name: feedback-no-failure-text
description: Never describe what happens when a technique fails — it is implicit and unnecessary
metadata:
  type: feedback
---

Never include failure-case text in technique effect blocks (e.g., "Si fallas, el ataque se resuelve normalmente"). The failure case is always implicit: the technique did not activate, so the normal game rules apply without change.

**Why:** The failure text adds nothing — it is obvious — and clutters the card. The user corrected this explicitly when Donde No Estás had a "Si tu T.E. es menor..." sentence.

**How to apply:** Write only what happens on success. Stop there. Never add a sentence explaining the failure path.
